# Alumwit rules

A portal for alumni of Mahidol Wittayanusorn School (MWIT). Idea stage: no code and no tech stack yet. The plan is
`docs/briefs/2026-11-10-alumwit.md`.

This repo is public. Anyone can read every file, issue, pull request and commit, and none of it can be taken back.

## Never
- Put a real person's details here: no real names, emails, photos or batch lists, in code, test data, issues, pull
  requests, screenshots or commit messages. Make up people.
- Send real alumni data to an AI model provider.
- Commit secrets: keys, tokens, passwords or `.env` files.
- Choose a framework, database or host. The stack isn't decided, so ask the owner.
- Change who can log in or who can see what without the owner's written OK on that pull request.

## Always
- Every screen works in Thai and in English.
- Every profile field obeys that person's visibility setting: public, members-only or private.
